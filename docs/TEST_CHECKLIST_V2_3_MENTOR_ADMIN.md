# Checklist v2.3

1. Login com conta existente.
2. No Swagger, executar `POST /api/v1/dev/make-me-mentor`.
3. Fazer login novamente.
4. Confirmar abertura da Área da Mentora.
5. Abrir Metodologia da Mentora.
6. Salvar uma regra, por exemplo: `CPA-20 não é essencial para autoridade`.
7. Criar uma nova conta de mentorada.
8. Confirmar tela `Aguardando aprovação`.
9. Voltar à conta da mentora.
10. Aprovar a mentorada.
11. Entrar novamente como mentorada.
12. Confirmar liberação da Home e dos módulos.

IP mobile desta versão:
`http://192.168.0.10:8001/api/v1`
