# v0.2 — Diagnóstico do Pilar 1

## Novas rotas

GET `/api/v1/diagnosis/positioning`

POST `/api/v1/diagnosis/positioning/answer`

Exemplo:
```json
{
  "question_key": "professional_trajectory",
  "answer_text": "Trabalhei por cinco anos no setor bancário e cheguei à educação financeira..."
}
```

A resposta retorna:
- score da resposta;
- progresso do pilar;
- status;
- próxima pergunta.

## Importante
A avaliação nesta versão ainda é determinística.
A próxima versão conecta o diagnóstico ao motor de IA para avaliar profundidade, coerência, autoridade e necessidade de aprofundamento.
